Modern Rapid Development

Yii3 предоставляет мощные инструменты для быстрого создания современных веб-приложений, включая генераторы кода и готовые компоненты. Интеграция с новейшими PHP-технологиями позволяют разработчикам сосредоточиться на бизнес-логике, а не на рутинных задачах.

High quality code

Yii3 способствует написанию чистого, поддерживаемого кода, следуя лучшим практикам и паттернам проектирования. Фреймворк следует PSR стандартам (PHP-FIG), обеспечивая совместимость с другими библиотеками и инструментами. Встроенные инструменты для тестирования, отладки и статического анализа помогают поддерживать высокое качество кода на протяжении всего жизненного цикла проекта.

Scales well

Built-in security

Yii3 обеспечивает надежную защиту веб-приложений благодаря встроенным механизмам безопасности, которые противодействуют распространенным угрозам, таким как XSS, CSRF и SQL-инъекции. Регулярные обновления и следование лучшим практикам в области безопасности позволяют разработчикам создавать защищенные приложения с минимальными дополнительными усилиями.

Component-based Architecture

Yii3 построен на основе независимых компонентов, которые можно использовать как вместе, так и по отдельности:

  • Возможность использовать отдельные пакеты Yii3 в любых проектах
  • Создание собственного фреймворка на базе компонентов Yii3
  • Все компоненты следуют PSR стандартам, обеспечивая отличную совместимость
  • Подход, схожий с Symfony, позволяющий интегрировать компоненты в любые PHP проекты

Flexibility

Yii3 адаптируется под ваши потребности, а не наоборот:

  • Поддержка различных структур приложения
  • Возможность организовать код так, как удобно вашей команде
  • Легкая интеграция с существующими проектами и сторонними библиотеками
  • Свобода в выборе инструментов и подходов к разработке

Генерация кода при помощи Gii

Для достижения этой цели всё, что вам нужно, это просто ввести необходимую информацию в соответствии с инструкциями, отображаемыми на веб-страницах Gii.

config/web.php
namespace App\Yii3\Resources;
use App\Yii3\Pages\Post\PostDetailPage;
 
class PostResource extends ModelResource
{
    protected string $model = Post::class;
 
    protected string $title = 'Posts';
 
    //...

После этого используйте генератор кода для создания моделей, CRUD и многого другого.

Затем настройте сгенерированный код в соответствии с вашими потребностями.

Psalm

Каждая строчка кода проверена на типы данных и потенциальные ошибки. Это значит, что в вашем проекте не будет неожиданных сбоев из-за неправильных данных или скрытых ошибок в коде.

~100%

PHPUnit

Все компоненты системы охвачены UNIT-тестами. Вы можете быть уверены, что при обновлениях или изменениях кода система продолжит работать как часы - любая проблема будет поймана до того, как попадёт к пользователям.

~100%

Infection MSI

Тесты успешно ловят даже малейшие отклонения в работе кода. Это гарантирует, что ваше приложение защищено от неочевидных багов и всегда работает именно так, как задумано.
